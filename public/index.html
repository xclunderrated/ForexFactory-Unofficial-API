This is a small, unofficial API that reads the ForexFactory economic calendar and returns it as JSON or CSV. Every endpoint is a plain GET, so you can open any of them in a browser.

Base url

http://localhost:3000

Endpoints

/api/v1/today
today's releases
/api/v1/yesterday
yesterday's releases
/api/v1/tomorrow
tomorrow's schedule
/api/v1/high-impact
only red-folder events
/api/v1/calendar
any date, with the filters below
/api/v1/calendar/2024-05-15.csv
one day as a CSV file
/api/v1/currencies
currencies seen in today's data
/api/health
a quick "is it alive" check

Filters

Add any of these to /api/v1/calendar as query parameters. You can combine them.

date
today, yesterday, tomorrow, or 2024-05-15
currency
one or more codes, separated by commas — USD,EUR,GBP
impact
High, Medium, Low, Non-Economic
search
a word from the event title — CPI
hasActual
true returns only events that already have a released number
limit
maximum number of events to return — 10
format
json (default) or csv

Examples

High-impact USD events today, from a terminal:

curl "http://localhost:3000/api/v1/calendar?date=today&currency=USD&impact=High"

In JavaScript:

const res = await fetch("http://localhost:3000/api/v1/calendar?date=today&impact=High");
const data = await res.json();

for (const event of data.events) {
  console.log(event.time, event.currency, event.title, event.actual);
}

In Python:

import requests

res = requests.get("http://localhost:3000/api/v1/calendar", params={
    "date": "today",
    "currency": "USD,EUR",
    "impact": "High",
})

for event in res.json()["events"]:
    print(event["time"], event["currency"], event["title"])

In Google Sheets:

=IMPORTDATA("http://localhost:3000/api/v1/calendar/today.csv")

Good to know

  • Repeated dates are cached: 3 minutes for today and future dates, 24 hours for past dates.
  • Times are exactly as published by ForexFactory. The API does not convert timezones.
  • This is unofficial and unaffiliated with ForexFactory. Keep request rates sensible.
